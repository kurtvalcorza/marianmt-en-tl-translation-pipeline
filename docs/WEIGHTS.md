# Weight provenance and DIMER hosting

- Upstream: `Helsinki-NLP/opus-mt-en-tl`
- Immutable revision: `e46e1761492cb6a6fb9515a72bb55ca654815ca5`
- Weight format: **PyTorch pickle** (`pytorch_model.bin`, 296,434,867 bytes, float32) — the only weight file upstream at this revision; there is no `model.safetensors`. SHA-256 `e418d573a717b2c81eaa3a80c8eb68f203c14c6b734dd36d41708c1369d0eb44`, recorded in the manifest and re-computed before every load.
- Upstream weight license: Apache-2.0 (`license: apache-2.0` in the pinned upstream README front matter). Trained by the Helsinki-NLP group (OPUS-MT, Tiedemann & Thottingal 2020) on the `opus+bt` dataset with the `transformer-align` architecture; original Marian weights at `opus+bt-2020-02-26.zip` (pinned README).
- Local layout: `weights/opus-mt-en-tl/` holds the 8 files listed in `dimer-base-manifest.json` (`config.json`, `generation_config.json`, `pytorch_model.bin`, `source.spm`, `target.spm`, `tokenizer_config.json`, `vocab.json`, upstream `README.md`; `totalBytes` 299,423,522) with byte size and SHA-256 for each. `verify_snapshot()` in `src/marianmt_translation_pipeline/pipeline.py` checks all of them before any load; `stage_missing_files(allow_download=True)` fetches only absent entries at the pinned revision into that directory. `.bin` and `.safetensors` files are git-ignored; the Git repository vendors neither the checkpoint nor its conversion.
- DIMER hosting: Apache-2.0 permits use, modification, redistribution and commercial use subject to preservation of the license and notices. DIMER may mirror the pinned checkpoint in its model store under those terms; the mirror must carry the same SHA-256 so the pipeline's digest check keeps holding.
- Loader trust boundary (pickle checkpoint): `verify_snapshot` re-hashes `pytorch_model.bin` against the manifest **before** `torch` or `transformers` is imported, so a modified pickle never reaches a deserialiser; then `convert_checkpoint` reads it once with `torch.load(..., weights_only=True)`, whose restricted unpickler admits tensors, primitives and containers only, and writes the pinned conversion; `from_pretrained` serves the model only from the safetensors conversion: `verify_converted` checks its pinned SHA-256, `MarianMTModel` is built from the verified `config.json` (with the snapshot's `generation_config.json`) with no Hub access and no repository code, and the conversion is loaded with `load_state_dict(strict=True)`; the serving path never calls `torch.load`, and once the conversion exists `pytorch_model.bin` is neither required nor read. The Hub is consulted only when `allow_download=True` is passed explicitly, and then only at the pinned revision.
- Served file: `model.converted.safetensors`, the model's state dict converted once from `pytorch_model.bin` by `convert_checkpoint` (`torch.load(..., map_location="cpu", weights_only=True)`, strict-loaded into `MarianMTModel` built from the verified `config.json`, written with `safetensors.torch.save_file` and the one-key metadata `{"format": "pt"}`); 296,409,812 bytes, 256 tensors, SHA-256 `1c7747e1f1da8e6969b16a8f1cba761ea23d28ec9d8dd6cf91b8571c710e92c2` (pinned as `CONVERTED_SHA256`). The four tied names (`model.shared.weight`, `model.encoder.embed_tokens.weight`, `model.decoder.embed_tokens.weight`, `lm_head.weight`) share one tensor, so it is stored once, under `model.shared.weight`, as transformers' own safetensors save stores it; the loader restores the other three names from it before `load_state_dict(strict=True)`. The pickle holds no `lm_head.weight` (it is tied) and stores `model.shared.weight` and both `embed_tokens` names as one shared tensor, which the converter checks. One deliberate difference from `save_pretrained`: it also leaves out the two sinusoidal `embed_positions.weight` tables (`_keys_to_ignore_on_save`), which this file keeps, equal to the pickle's values, so that `load_state_dict(strict=True)` needs no exception. Converting twice gives the same bytes; a result with any other digest is deleted and refused.
- Equivalence: 2026-10-24, CPU, torch 2.14.0, transformers 4.57.6: the model served from the conversion and the model `MarianMTModel.from_pretrained(<verified dir>, use_safetensors=False, weights_only=True)` loads from the pickle have identical state dicts (every tensor `torch.equal`, the same four-way tie), identical generation configs, identical logits on three English sentences (max abs difference 0.0) and identical 4-beam translations (`Ang mga bata ay naglalaro sa parke.`, `Hindi ako kumain ng isda.`, `Mayroon kaming tatlong aso at dalawang pusa.`).

## Adaptation corpus (not redistributed)

- Source: Tatoeba en–tl, OPUS Moses release `v2023-04-12` — `https://object.pouta.csc.fi/OPUS-Tatoeba/v2023-04-12/moses/en-tl.txt.zip`, 312,459 bytes, SHA-256 `9abddc7d2fcea307e8582285617d1a10246fdb9050b6c6345243cb4b9991f40b`; members `Tatoeba.en-tl.en` / `Tatoeba.en-tl.tl`, 8,785 aligned pairs (7,741 after this repository's length filter and case-insensitive English-side de-duplication).
- Licence: CC BY 2.0 FR (Tatoeba contributors; redistributed by OPUS). Attribution is carried in `CORPUS_LICENSE` and in every result export's `corpus` block.
- Handling: `fetch_corpus` verifies the byte count and SHA-256 before the zip is read, reads the two members with `ZipFile.read` (no `extractall`), and caches the verified zip under `weights/tatoeba-en-tl/` (git-ignored). The repository ships no copy of the corpus; only the digest, the seed (`SAMPLE_SEED = 42`) and the split sizes (`SAMPLE_SPLIT`) are committed, which reproduce the 1,200 / 200 / 300 records and their digests exactly.
- Adapter artifacts: `save_artifact` writes `adapter.safetensors` (the trained `model.decoder.layers.*` tensors only, 33,638,224 bytes for the default two blocks) plus `manifest.json` carrying `format` `org.valcorza.marianmt-en-tl.adapter.v1`, the base `model_id` / `model_revision` / `weight_sha256`, the tensor list and the file SHA-256; `load_artifact` refuses any mismatch. Adapters are derived works of the Apache-2.0 weights and of whatever corpus trained them; an adapter trained on the Tatoeba sample inherits the CC BY attribution obligation.
